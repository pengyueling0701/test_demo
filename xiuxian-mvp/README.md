# 一炉尘梦 · 持续生产与挂机修行 H5 v0.17.0

手机竖屏的古风修仙原型。以家园持续生产和秘境修行双主线为核心：上线集中收获，安排丹房生产，服丹成长、升级家园，再手动挑战新关卡，提高长期挂机收益。原有自动存档沿用，不需重新开始。

## 本轮修改

- 取消借贷、计息、催收和债务失败。保留原现金、库存、家园、技能及秘境记录；旧失败存档恢复经营。旧债务仅归档，不兑换现金。
- 开局自动积累修为和灵石。在线离线同效率，收益池最多储存24小时；领取不推进游戏日。
- 药田消耗一份种子启用持续培育，领取后继续产出。初始教学首批一分钟；青灵草正常20分钟一批、月华30分钟、焰心及霜露40分钟。每块药田待收量最多24小时产量。
- 药田可逐块管理，集中收获中可批量启用空田青灵草。特殊草药仍需境界和土地条件。换种前先领完产物、停止培育，再投入新种子。
- 丹房提交一批同款丹药，提前投入材料，离线逐枚炼制。每枚实际耗时60秒＋品质序×45秒；工作台减时20%。队列容量6＋丹炉等级×4。
- 炼丹不消耗精力、灵石或矿石；成功增加10经验，失败材料作废。提交时固定本批成功率与随机结果，读档不重抽；未开始部分可取消，返还材料在丹房领取，正在炼制的一枚继续。
- 家园右侧小型“收获”入口集中领取修为、灵石、草药、丹药和取消材料。物品优先领取丹药与返还材料，再领取灵草；放不下的部分留在原处。
- 蒲团查看最高历练进度、小时收益、积累时间及领取。修为满条自动提升小等级；十级手动消耗对应突破丹，溢出经验保留。
- 青岚竹海分为外围、腹地、首领三关，分别清除指定妖兽后完成；越过地形不算完成。撤离与战败保留已完成关卡，下次从检查点继续。
- 其余九境沿用同样的外围、腹地、首领战斗完成条件和检查点，保持原有地图与境界门槛。原动作战斗、四技能、五行克制、服丹与丹毒保留。

## 计时与收益

生产和挂机使用现实时间；休养一天不会加速现实生产。订单、集市及扫荡仍按游戏日刷新；离线不自动推进游戏日，也不自动恢复精力或清除丹毒。

最高进度P为秘境序号×3＋已完成关数（序号从0计）；未探索为0，青岚三关为1/2/3，各境分别记录1/2/3关。重复完成不叠加效率。

初版修为/小时为120×1.085^P，洗髓资质提升后翻倍；灵石/小时为60×1.12^P，分别取整。青岚首领通关后为153修为与84灵石/小时。提高效率前按旧效率结算过去时间，不追溯抬高旧收益。

成长经验为80＋(境界序号×10＋小等级－1)×20。初始炼气五级，当前可修至元婴十级。三张突破丹方开局已掌握：筑基丹、结金丹、元婴丹分别用于炼气→筑基→金丹→元婴。突破丹为可在进阶前炼制的特殊丹方；普通高级丹药需金丹，稀有和传说需元婴。

首次收获任务额外奖励40修为，首次成丹任务80修为，各领取一次，辅助首次小等级成长；旧存档已领取的任务不补发。

# v0.19 手动炼丹（2026-10-13）

本节替代旧自动炼丹操作流程。点击家园炼丹炉进入独立场景，背景随破败、青铜、精铁、灵纹、紫霄、太虚六档丹炉变化。初始破败丹炉。

点击丹炉选择丹方及同款数量，数量上限沿用丹炉容量及实际材料限制。每次只炼一种丹的一批。

操作顺序：选丹方与数量 → 逐份拖入材料 → 点击药杵或捣药按钮 → 全部成为药泥后生火 → 调整炉火滑条，将炉温保持在移动的绿色区间 → 结算领取。也可点选材料，再点击炉口投入。

选定批次时取出所需材料，优先低品质材料，拖入时不重复扣除。生火前取消返还原品质材料，背包不足部分留在丹房。生火后不能取消返还；离开页面或退出游戏暂停，返回继续。新流程不再离线自动完成，旧存档的自动队列仍可按原方式完成。丹炉有当前批次时不能切换丹方或升级。

每批耗时18秒 + 丹药品质等级×3秒 + min(10,数量−1)秒。炉温逐渐靠近炉火强度，绿色区间随时间变化。稳定度为处于合适区间的时间占比；最终成功率为基础成功率 + (稳定度−0.5)×24，限制10%至100%。基础成功率仍关联修为和炼丹等级。每枚独立判定，随机值保存，不因读档重新抽取。

成功每枚增加10炼丹经验，失败材料作废；成品留在丹房，背包满时不会丢失。炼丹不消耗灵石、矿石或精力，升级丹炉仍消耗矿石和灵石。

美术通过内置image_gen生成，原PNG直接保存：public/art/alchemy-rooms-v1.png（三列两行六档丹房）；public/art/alchemy-process-v1.png（透明药泥、药杵、火焰、成丹图集）。使用CSS取单格，无二次修改。

98项规则测试通过；390×844触摸浏览器走通两枚丹药的选方、拖料、捣药、生火、控火和领取，火候稳定度96%、成功率89%，无运行错误。验证批次互斥、暂停读档、原品质材料返还、多种材料、背包容量和重复结算。尚未验证实体手机。
