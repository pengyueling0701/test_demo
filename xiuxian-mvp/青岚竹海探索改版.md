# 青岚竹海：路线探索与回合战斗（v0.22.0）

本次先将青岚竹海改为五节点探索，其他九个秘境保留现有横版战斗及解锁门槛。原有家园、种植、手动炼丹、背包、技能和存档继续使用。

## 玩家循环

种植材料 → 炼制回春丹／回灵丹 → 配置装备、最多四个已学技能和本趟丹药数量 → 进入青岚竹海 → 选择采集或战斗 → 撤离带回材料 → 升级丹炉、扩容背包并炼制新丹。

准备页显示武器、攻击、防御、生命、法力、丹毒和携带技能；调整装备与技能进入人物面板。丹药数量不超过背包库存，未使用的不扣除，不能在途中使用未选入行囊的丹药。入场消耗30精力，返程不再扣精力，也不会借日期恢复抵消入场消耗。往返各推进一个游戏日。

## 五个节点

| 节点 | 可选行动 | 特点 |
| --- | --- | --- |
| 竹林入口 | 采药／战斗寻宝 | 木属性青竹獠鼠 |
| 溪边岔路 | 采矿／战斗寻宝 | 土属性青竹獠鼠，提醒准备多属性技能 |
| 御风古碑 | 参悟古碑 | 永久领悟御风步，获得月华草及种子 |
| 竹海深处 | 采药／战斗寻宝 | 木属性竹影妖狼，深处采药量更高 |
| 兽王巢穴 | 挑战兽王 | 木属性青岚兽王，击败后返回结算 |

采药、采矿有25%概率惊动妖兽；采集材料先进入临时行囊。每趟从第一节点重新开始，历史最高关卡不会下降，第二、第四节点完成及击败兽王分别记作外围、腹地、首领三段，继续提高既有挂机修为效率。挂机不产灵石。

## 回合与资源

每次普通攻击、技能或战斗服丹后，存活的妖兽行动一次；击杀后不再反击。妖兽显示下一次意图，依次为扑击、蓄力、重击、回复。蓄力回合不造成伤害，可以用于服丹。普通攻击取人物攻击，技能使用现有固定伤害及品质加值；五行克制仍为两倍伤害。技能消耗法力，只能使用出发时携带的最多四种技能。

同一趟生命、法力、丹毒跨战斗保留，节点间不自动恢复。服丹按既有丹毒衰减药效，丹毒满100禁止服用。战斗外可使用携带丹药，不触发妖兽行动。战斗内外均可立即撤离，带回完整临时资源；战败保留每种资源数量向下取整的一半，不损失原有背包物品。回家生命回满，法力和丹毒沿用现有返程规则，包括正常一游戏日的丹毒消退。

首版平衡：普通妖兽生命55＋节点序号×15，兽王220；普通妖兽扑击12、重击22、回复8，兽王20／34／18；实际伤害减防御，最低3。普通胜利掉兽皮2、内丹1、灵草2＋节点序号，兽王掉兽皮4、内丹2、灵草5，额外掉月华仙草3和种子2。以上是原型参数，目标是一趟3—5分钟，尚需玩家实际操作反馈调整，不以自动化耗时视为真人体验时长。

## 结算与存档

结算展示已入背包资源、丹药消耗、完成关卡与挂机效率变化。背包放不下的合法战利品保存在待领区，已有整理领取入口继续可用。首次通关解锁青岚扫荡及凝露丹方，扫荡规则仍为30精力、一次、七个游戏日恢复。

每次行动自动保存探索位置、妖兽生命与意图、法力、丹毒、携带丹药余量、临时资源。刷新页面继续本趟，不重复扣入场精力。结算后清除进行中的探索，不能再次领取。旧存档不重置角色或资产。
