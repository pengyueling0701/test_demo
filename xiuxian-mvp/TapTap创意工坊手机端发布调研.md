# TapTap 创意工坊手机端发布调研

调研日期：2026年10月6日。目标为本项目的 H5 作品在 TapTap 创意工坊手机端提供游玩。本次仅准备本地包体和资料，不创建平台游戏、不上传、不提审。

## 1. 适合当前项目的发布路径

当前项目是 JavaScript + Canvas 的 H5 游戏，适合选择「快速上架（创意工坊）」的 H5 包体路径。TapTap 的开发者指引将 H5、Tap 小游戏（WebGL）、APK 和 TapTap 制造区分为不同形态，各自使用对应接入文档；因此本项目无需为当前目标先转换为 APK 或星火编辑器工程。[官方 AI 开发者指引](https://developer.taptap.cn/agents/)

官方入驻文档明确：注册开发者可创建创意工坊游戏，所需基础信息为厂商名称、邮箱与经过验证的手机号；个人或企业认证开发者有额外的身份材料。能创建草稿不等于已满足发布条件，最终以账号后台的实际要求为准。[开发者入驻说明](https://developer.taptap.cn/docs/store/)

## 2. H5 手机端上传流程

TapTap 2026聚光灯发布教程的「快速上架（创意工坊）H5」部分给出以下旧版后台流程，可作为入口参考；后台改版时按实际页面操作：

1. 创建游戏并选择「快速上架」，按内容选择适龄分级，核对开发与发行角色。
2. 阅读创意工坊内容授权协议，由账号持有人确认相关条款。
3. 在「游戏包管理 → 小游戏管理」上传 H5 ZIP 包体，更新时递增版本号。
4. 回到资料页「游戏下载和获取 → H5小游戏」，选择刚上传的包体；上传和绑定包体是两个步骤。
5. 将要发布的手机平台配置为「提供游玩」，检查简介、图标、截图、版本信息，再自测和提审。

该教程包含活动专属的参赛资格与安卓包说明；本项目只采用其中 H5 创意工坊部分，不将参赛身份、截止时间或 APK 防沉迷配置搬到本项目。[TapTap 上传教程：H5 创意工坊部分](https://www.taptap.cn/moment/854478404412507237?group_id=792849)

官方包体管理文档支持为 H5 获取自测二维码。上传后应通过平台生成的二维码在自己的手机上测试，再检查发布资料和提审状态；本地浏览器成功不代表 TapTap 容器已经验证。[包体管理与二维码自测](https://developer.taptap.cn/v3/cli/skills/taptap-package-management.md)

## 3. 本项目包体与移动适配

本地构建输出由根目录的 `index.html` 和 `assets` 组成，构建资源使用相对路径，避免平台以子目录部署时找不到脚本。ZIP 只包含构建结果，不包含源码、node_modules、开发服务器或本地存档。

项目已经提供：像素画布、底部场景切换、触屏战斗按钮、竖屏经营与竖屏战斗布局、底部安全区适配。山居与秘境背景、散修角色、丹药与道具图集由内置生图工具生成，PNG 随包体提供。字体使用系统字体，无外部字体或图片下载依赖。

手机自测重点：

- Android 与拟发布的 iOS 端是否都能打开，控制台中是否分别配置了提供游玩。
- 刘海与手势安全区不遮挡顶部状态栏或底部场景按钮；横转显示竖屏提示并暂停战斗，转回后不丢状态。
- 同时按住移动与跳跃／攻击时，多点触控是否有效，离开按钮后是否释放输入。
- 切到后台再恢复，不发生错误时间推进或意外战败。
- 种田、炼丹、7日订单、30日催债、秘境返回和更新后的存档恢复正常。
- 所有资源能在平台子目录中加载；没有浏览器开发服务器地址依赖。

## 4. 发布前尚需确认的事项

**资质与协议**：普通手游正式上线规则不直接等同于 H5 创意工坊规则；普通小游戏的前置备案文档也明确提示，创意工坊和 TapTap 制造应以各自实际要求为准。不能据此保证本作品免版号、免备案或免其他审核材料，需在当前账号的发布页与资质页核对，必要时通过官方工单确认。[小游戏前置备案的适用范围说明](https://developer.taptap.cn/minigameapidoc/quick-start/guide/pre-filing/)

**素材与内容**：准备正式游戏名称、开发者名称、游戏图标、实机截图、简介、操作说明与适龄分级。本原型的「一炉尘梦」为暂定名。正式提交前核对剧情表现、美术与名称的权属；原设定中的暴力催债背景需结合实际内容分级与平台审核处理。

**存档**：当前仅使用浏览器 localStorage；更换站点、设备或清理应用数据可能丢失存档。平台域名更新后的存储隔离、WebView 可用性需要真机验证。尚未接入 TapTap 登录或云存档，不应宣传跨设备同步。

**平台能力**：目前不包含广告、付费、联网后端或平台 SDK。若增加登录、云存档、广告，应使用 H5 对应的官方接入方式并更新隐私说明，不将原生 APK SDK 或 WebGL 小游戏 API直接复制进来。[H5 对应接入入口](https://developer.taptap.cn/minigameapidoc/quick-start/mcp-guide/mcp-setup/)

**当前结论**：可准备 H5 ZIP 供创意工坊手机端上传和自测，但尚未进行平台包体校验、TapTap 手机真机测试、资质检查或提审。项目测试通过不等于平台审核通过。
