# 古风修仙种田游戏设定 · 一炉尘梦

版本：v0.17.0；更新日期：2026-10-12。本文记录当前手机竖屏H5原型的规则；数值仍属试玩版本。

## 定位与故事

玩家扮演资质低劣、五灵根的底层散修。遭债主逼迫后回到乡下老屋，发现失传丹方和破败丹炉，开始重建家园、炼丹修行，寻找改变资质的机会。欠债只作为开场背景，取消贷款、周期催收、资产扣除与债务失败。

核心为家园持续生产与秘境修行双主线。上线集中收获 → 经营交易、炼丹服丹与设施升级 → 手动挑战秘境 → 提高挂机收益并发现新资源 → 安排下一轮生产。

## 初始状态与成长

炼气五级，现有资金500灵石，八份青灵草种子、四块普通药田、破旧老屋、破败丹炉。初始学会金锋剑气，具有五灵根，可学习五系技能；秘境最多携带四种。

开局掌握筑基丹、结金丹、元婴丹丹方。小等级修为门槛递增，满条自动升级；每境十级积满经验后需手动突破，依次消耗对应突破丹。溢出修为保留。当前境界上限为元婴十级；后续世界观顺序为化神、炼虚、合体、大乘、渡劫，但本版尚未开放。

蒲团领取持续修行所得，修炼丹药用于加速。首次收获任务奖励40修为，首次成丹任务80修为，任务奖励主动领取且不重复。

## 药田与家园经营

药田选择草药和种子品质，消耗一份种子启用持续培育。后续自动生产，领取不清空种植计划、不重复消耗种子或精力。初始教学首批一分钟产出，正常青灵草20分钟、月华30分钟、焰心及霜露40分钟一批。每块药田最多存24小时产量，达到上限暂停积累，满仓未领取产物保留。

特殊草药仍要求对应土地与境界。收获可用于订单、出售或炼丹；种植熟练度提高每批产量。换种或改土前先领完产物并停止培育。

住宅升级解锁更多药田容量和储物空间，四级上限4、6、8、12块，扩建另付灵石。家具同类增益不叠加；储物柜加40容量、竹榻增加休养恢复、工作台缩短炼丹耗时20%。家园支持拖动、缩放、布置、摆件回收与重新放置；住宅和丹房可移动不可回收。家园仓库只收纳家具和摆件，材料与丹药在背包。

## 炼丹与交易

丹药、武器、装备等生产品六档：粗制、初级、中级、高级、稀有、传说；仙草与内丹五档：初级至传说。普通高级丹药需金丹，稀有与传说需元婴。三种突破丹方允许在目标境界之前炼制，避免进阶材料被进阶门槛锁住。

丹房安排一种丹药的一批队列，预扣整批材料，在线离线逐枚完成。队列容量6＋丹炉等级×4；每枚耗时60秒＋品质序×45秒，工作台减时20%。不消耗灵石、矿石或精力。成功率绑定修为、炼丹等级与丹药品质，提交时记录本批概率和随机结果；读档不重抽。

成功一枚增加10经验，失败材料作废且无经验。成品待领取，背包不足仍留在丹房。可取消未开始的部分，材料原品质返还到丹房待领取区；正在炼制的一枚继续完成。

丹炉从破败、青铜、精铁、灵纹到紫霄、太虚，升级消耗灵石和矿石。商店不卖丹炉，卖矿石、种子、材料、丹药、技能书、武器及八部位装备；展示详情，不卖传说物品。洗髓天灵丹不可买卖，凝露丹须通关青岚发现丹方。

集市每七游戏日刷新，商品便宜、不提前展示详情，小概率出现传说物品。道友订单每七游戏日刷新，需求匹配当前境界的可生产丹药。商品和订单仍是主动经营灵石的主要来源。

## 挂机修行与历练

开局自动积累修为和少量灵石，在线离线效率相同。按最高已完成秘境及关卡计算小时收益，解锁、进入或重复通关不提高效率。收益池最多24小时，蒲团及集中收获入口可领取。

进度P=最高完成秘境序号×3＋完成关数，未探索为0。修为每小时120×1.085^P，灵石每小时60×1.12^P，分别取整。洗髓后修为效率翻倍。提高效率之前按旧效率结算旧时间，提升只影响之后积累。

挂机提供稳定成长，丹药加速升级；挂机不直接提供完整装备、突破丹或稀有药引，保留生产与手动探索的价值。原型通过时间结算模拟离线历练，不在关闭页面后实际运行战斗。

## 秘境与战斗

筑基解锁御剑外出。十个秘境沿用原场景，进入与扫荡消耗30精力。青岚竹海分外围、腹地、首领三关：分别击败前两只妖兽、腹地三只妖兽、镇境首领，越过地图位置不能算通关。先完成前两关才能击败首领。撤离或战败保留已完成关数，下次从检查点继续。

其余九境采用相同的外围、腹地、首领条件，分别记录关卡完成与检查点，沿用原地图和妖兽配置。门槛为筑基1/4/7/10级、金丹1/5/10级、元婴1/5/10级。

动作战斗保留移动、跳跃、御风碑二段跳、近战和点击技能。金克木、木克土、土克水、水克火、火克金，克制技能造成两倍伤害。技能消耗法力，回灵丹恢复法力；回春丹回血，丹毒影响服丹，满100不能服丹。气血仅在秘境HUD显示，离开秘境回满。

通关每境解锁一次扫荡，使用后七游戏日恢复，不累计。扫荡补材料，持续挂机提供修为和灵石，两者分别结算。

## 时间、界面与存档

生产与挂机按现实时间计时。订单、集市、扫荡继续以主动行动推进的游戏日计时；休养不能跳过现实生产。离线不推进游戏日、不清丹毒或回精力。

手机竖屏，底部仅外出／回家／人物。回家显示家园，住宅进入室内，蒲团查看修行；丹房和药田通过场景交互操作。家园右侧收获入口一键收取，优先丹药与返还材料，再收灵草；满仓只领取能装下的部分，其余保留。任务由感叹号入口打开，分进行中与已完成。

沿用本地存档，不清资产、技能或秘境记录。旧债务归档、失败状态解除；旧药田转为持续培育，旧通关转为三关完成，新增挂机从功能启用时开始计时。已领取任务不补发奖励。

## 主线与验证范围

阶段目标为草庐立足、稳定生产、筑基御剑、青岚探索、发现丹方与炼成洗髓丹。服用洗髓天灵丹完成逆天改命，之后仍可经营与探索。

本版已做规则测试、实际战斗引擎测试、固定种子完整流程模拟和390×844触屏浏览器检查。未完成实体手机与TapTap容器实测，长期平衡与秘境差异化继续迭代。
本地H5原型根据本机时间结算，正式联网版本应改用服务端时间与存档。完整长期平衡与真机验收为后续工作。
## v0.18 家园与作物更新（2026-10-13）

家园采用固定九宫结构，初始九块普通药田。左上练功房用于修炼、领取修为与突破，右上炼丹炉用于炼丹。外出与人物入口沿用。取消家园仓库和自由布置入口；旧存档资产与作物保留，已购买及收纳家具的增益保留。

左右滑动查看土地页面：普通土地开局开放，灵土筑基开放（800灵石）、赤炎土金丹开放（1400灵石）、寒霜土元婴开放（1800灵石）。每次开辟一页九块田；旧特殊土地补齐对应页面。初始8份种子可先启用8块田。

四种草药均有种子、幼苗、植株、成熟四阶段。周期前25%为种子，25%至60%为幼苗，其后为植株；有待收库存时显示成熟。领取后继续下一轮实际生长进度。阶段表现不改变产量、周期或材料扣除，在线实时更新，离线按现实时间恢复。

生成素材：public/art/garden-grid-v1.png、public/art/crops-four-stages-v1.png。内置image_gen生成，原PNG直接保存；四行分别为青灵草、月华仙草、焰心草、霜露仙草，四列分别为四阶段。

验证：92项测试通过；390×844竖屏浏览器走通播种、练功房、四阶段展示、触摸滑动。无运行错误。尚未做实体手机验证。
# v0.19 手动炼丹（2026-10-13）

本节替代旧自动炼丹操作流程。点击家园炼丹炉进入独立场景，背景随破败、青铜、精铁、灵纹、紫霄、太虚六档丹炉变化。初始破败丹炉。

点击丹炉选择丹方及同款数量，数量上限沿用丹炉容量及实际材料限制。每次只炼一种丹的一批。

操作顺序：选丹方与数量 → 逐份拖入材料 → 点击药杵或捣药按钮 → 全部成为药泥后生火 → 调整炉火滑条，将炉温保持在移动的绿色区间 → 结算领取。也可点选材料，再点击炉口投入。

选定批次时取出所需材料，优先低品质材料，拖入时不重复扣除。生火前取消返还原品质材料，背包不足部分留在丹房。生火后不能取消返还；离开页面或退出游戏暂停，返回继续。新流程不再离线自动完成，旧存档的自动队列仍可按原方式完成。丹炉有当前批次时不能切换丹方或升级。

每批耗时18秒 + 丹药品质等级×3秒 + min(10,数量−1)秒。炉温逐渐靠近炉火强度，绿色区间随时间变化。稳定度为处于合适区间的时间占比；最终成功率为基础成功率 + (稳定度−0.5)×24，限制10%至100%。基础成功率仍关联修为和炼丹等级。每枚独立判定，随机值保存，不因读档重新抽取。

成功每枚增加10炼丹经验，失败材料作废；成品留在丹房，背包满时不会丢失。炼丹不消耗灵石、矿石或精力，升级丹炉仍消耗矿石和灵石。

美术通过内置image_gen生成，原PNG直接保存：public/art/alchemy-rooms-v1.png（三列两行六档丹房）；public/art/alchemy-process-v1.png（透明药泥、药杵、火焰、成丹图集）。使用CSS取单格，无二次修改。

98项规则测试通过；390×844触摸浏览器走通两枚丹药的选方、拖料、捣药、生火、控火和领取，火候稳定度96%、成功率89%，无运行错误。验证批次互斥、暂停读档、原品质材料返还、多种材料、背包容量和重复结算。尚未验证实体手机。
