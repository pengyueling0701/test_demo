# 第三、四阶段实施与试玩

版本 v0.15.0，2026-10-06。

## 第三阶段：外围系统服务经营

商店保持公开价格、商品详细信息与稳定补货；订单按具体需求给予限量溢价；集市保持七日刷新、低价与信息不完整的采购体验。没有加入动态物价或联网交易。新增凝露丹只由探索丹方自行炼制，商店与集市不出售，商店可收购成品。

青岚竹海高处药谷新增月华种子2份，需在御风碑获得二段跳后回访。种子作为实际拾取物与本次战利品结算，撤离可带回，战败按现有减半规则，满包可能无法带回。不是额外自动赠送。

首次击败青岚兽王并成功返回后，永久发现青岚残卷、解锁初级凝露丹。配方为青灵草2株、月华仙草1株，要求筑基与青铜丹炉，修为+55、丹毒+10；回收900灵石。炼制沿用真实成功率、精力消耗、仅成功增长经验、失败材料作废规则，不消耗灵石或矿石。

月华种子需要整修木屋解锁灵土改造，再种植收获。回春与回灵丹用于战斗，回灵丹也用于生产仙术；凝露丹用于低丹毒修炼或出售。已发现丹方后，筑基的后续奇数周期修炼订单会需求2颗凝露丹；偶数周期仍需求高级凝元丹。旧订单保留到正常刷新，避免打断备货。

债务保持百万开局、1%利息、现金优先和零现金扣仙草的原规则；没有自动留钱、发救济或减免债务。债务面板增加周转清单与按正常价格购买两份种子的入口。24、28日提醒明确保留种子及仙草；种子与未收获作物不能代替库存仙草抵债。催收后可用剩余仙草卖一株购种，或直接播种续产。准备不足仍可能失败。

## 第四阶段：第一章与改命目标

新增七段短故事：旧屋与破炉、田里有活路、炉火重燃、御剑出山、青岚残卷、债去一程田还在、草庐立足。分别由主角、药师与剑修讲述。来信通过画面小按钮进入，也能从任务中重读；不强制弹出，不推进日期，不追加奖励，阅读状态保存。

任务面板保留进行中与已完成分类，新增章节进度、当前目标快捷入口、来信与洗髓丹线索。原有十项任务全部完成即标记第一章完成，不要求全部奖励已领取。完成后仍能正常经营。

第一章之后的明确目标是经营月华灵田、积攒妖兽内丹、突破金丹、升级传说丹炉，最终炼制并服用洗髓天灵丹；清偿债务与洗髓仍为原有主线结局。不是第一章完成就免债或改资质。

住宅升级增加少量像素装饰：整修后灯笼、小院盆栽、修仙宅院门幡。沿用现有背景、角色与图集；家具和药田沿用已有可见变化。没有扩展其余九个秘境内容。

## 存档

新增 journey 保存来信可用及已读记录、残卷发现、第一章完成。旧存档从已有任务和青岚通关记录推断进度，不清资产、不重置秘境、不补发种子或任务奖励。新丹方材料字段自动补齐；原有物品、订单继续有效。

## 验证与试玩记录

70项规则测试通过，覆盖发现门槛、战败不解锁、凝露丹失败消耗、材料种植到炼丹与订单、故事不重复发奖、章节判定、读档、催收后续产。浏览器检查了来信阅读、任务进度与手机竖屏布局；未做实体手机完整试玩。

完整模拟使用真实战斗帧循环，未借新贷款、未倒卖集市传说物品：第3日青铜丹炉，第25日筑基，第27日击败青岚兽王并回访高处药谷，实际带回月华种子2、青灵草9、月华仙草4、内丹2。第31日首期交易20,970、订单3,770、任务奖励750、经营支出2,130，经营净收入不含奖励22,610；利息10,000，催收23,860；剩余贷款986,140，现金0，仙草6，存活且十项目标完成。

随后以卖出3株月华仙草和4株青灵草所得1,620灵石，翻修木屋800、改造灵土800；收获已有作物后播种月华，至第34日收获并成功炼制服用凝露丹。此时现金20、月华种子1、月华仙草5、修为79、丹毒10。说明首期催收后仍能开展新的经营路线，而不是依赖额外救济。该结果为固定随机种子的程序模拟，不代表所有策略均能存活。
