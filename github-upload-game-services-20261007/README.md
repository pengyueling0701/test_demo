# 一炉尘梦 · 修仙炼丹经营 H5 v0.16.13

一个本地运行的中文古风游戏原型，使用原生 JavaScript、Canvas 与 Vite。底部仅保留外出、回家、人物，点击场景物件进入具体功能。以手机竖屏为唯一游玩布局，支持触屏战斗按钮与浏览器本地自动存档；电脑只显示手机尺寸预览。背景、主角、丹药与道具使用内置生图工具生成，具体提示词见 ART_GENERATION.md。无需账号与后端。

## 运行

```powershell
cd D:\program\test_demo\xiuxian-mvp
npm install
npm run dev
```

打开 http://127.0.0.1:5174 。`npm test` 运行规则测试；`npm run build` 生成 `dist` 静态文件。

## 入门路线

1. 四块药田播种，休息两日后收草；去道友订单交付或在仓库出售。
2. 直接使用破败丹炉炼粗制回春丹；花180灵石和2份赤铜矿升级后炼初级丹药；补购种子，保持生产。
3. 修炼一日增加28修为；每80修为升一级。初始炼气五级，炼气十级再次突破进入筑基。
4. 筑基后整理装备、准备回春丹，御剑进入青岚竹海。石碑解锁二段跳，上层药谷需要回访；兽王掉落内丹。
5. 收集6月华仙草、3内丹，达到金丹，配合太虚丹炉炼制洗髓天灵丹。服丹提高资质；还清债务后完成主线。

## MVP采用的明确简化

- 数值为快速验证玩法而设，不代表正式经济平衡。境界内十级，突破固定消耗80修为，最高金丹十级。
- 炼丹按修为与炼丹等级决定成功率；神识与炼丹熟练度展示成长，随机成丹规则见最新版本。作物有青灵草、月华仙草、焰心草与霜露仙草；特殊作物需筑基、种子及对应土地。月华仙草仍可购买或秘境采集；焰心草和霜露仙草当前可交易或抵债，可用于高品质丹方。
- 精力限制劳动；每日推进恢复精力与减少丹毒。每360游戏日计一年，寿元耗尽结局尚未实现。
- 当前额度 = 境界额度 × 剩余寿元/60（系数最高1.5），开局系数1。小等级不单独提高额度。
- 订单固定三类，批次略有变化；信誉解锁高级订单尚未实现。
- 家具购入即生效，尚无拖拽摆放；武器和装备在商店购买，人物面板穿戴，未增加耐久、随机词条或锻造。
- 十个秘境每次重置敌人与采集资源，永久保留二段跳，分别记录通关状态。出发与返回各消耗一日，战斗实时帧不推进经营日期；催债可能在出发或返回结算。
- 战败自动重伤撤回，现有资产保留，本次战利品保留一半；剩余回春丹与丹毒按实际使用结算。撤离可带回全部当次战利品，容量不足时丢弃装不下的部分。
- 商店不出售、不收购洗髓天灵丹。债主只扣草药，装备、丹药、非草药秘境材料不抵债。
- 存档仅保存在当前浏览器的当前站点；清理站点数据或更换端口会影响存档读取。不含云存档、付费、联网与移动端安装包。

## 通关扫荡

每个秘境首次成功通关后可一键扫荡1次，使用后从当前游戏日开始等待完整7日恢复，最多存1次，不跨秘境共用，也不因重复通关重置。旧存档已经通关的秘境同样解锁。扫荡直接领取该境的固定基础资源，不进入战斗，不消耗丹药、不增加丹毒，也不推进日期。背包不足时不领取、不扣次数。次数和恢复日期随存档保留。奖励为初版数值，可继续平衡。

按用户要求取消素材格式和重复地图遍历等额外检查，仅保留资源扣取、借还款、土地条件、等级门槛、扫荡冷却与重复领奖等必要规则测试。


## 丹炉品质、人物与仓库（最新规则）

破败丹炉无需修复，开局可直接炼制粗制丹药。品质依次为粗制、初级、中级、高级、稀有、传说。花灵石逐级升级丹炉，升级后能炼对应及更低品质。洗髓天灵丹属于传说级，不能在商店买卖。

商店新增武器与装备。装备分为头部、上衣、裤子、鞋子、背饰、挂饰、项链、戒指；购买后主动穿戴，同部位替换生效，不叠加。增加气血上限不会免费回血。

底部秘境之后新增人物、仓库入口。人物展示八个部位、武器及实际属性。仓库分类为种子、灵药仙草、矿物、妖兽材料、丹药、武器装备，可出售可交易物品、服丹和穿戴。装备收藏独立于材料仓储容量。

MVP默认数值：丹炉依次为破败、青铜、精铁、灵纹、紫霄、太虚；逐级费用180、600、1200、3000、8000灵石。灵纹需筑基，紫霄与太虚需金丹。战斗优先使用现有最高品质回血丹，用尽后切换较低品质，共用丹毒限制。旧存档保留库存、武器、衣袍；旧最高丹炉迁移为灵纹丹炉。


## 五灵根与技能（最新确认）

主角为金木水火土五灵根，可学习全部属性技能。所有现有物品均归属单一五行，包括种子、草药、丹药、矿物、妖兽材料、武器装备、丹炉、土地、住宅家具、丹方和灵石。五灵根与低劣资质并存，洗髓提高资质，不改变灵根。五行克制按下文最新规则生效。

秘境最多携带四种已学技能，人物面板学习、携带和卸下。初版开局自带金锋剑气；青藤破阵、寒潮灵波、赤焰焚击、厚土震岳分别花250、300、400、350灵石学习。五技能消耗法力分别12、14、16、20、18，攻击范围及倍率不同。上述费用、技能名和数值为MVP默认设定。

粗制回灵丹与初级回灵丹可购买、炼制、自用及出售，回复40、65法力并产生18、16丹毒。满法力或满丹毒不能服用，丹毒降低回复效果；秘境回灵丹按钮优先使用高品质库存。所有丹药共用丹毒。旧存档补齐五灵根和初始技能，保留原有资产。


### 五行克制与技能点击

土克水、水克火、火克金、金克木、木克土。技能命中被克制属性妖兽时，伤害 = 人物攻击 × 技能倍率 × 2；其余属性关系倍率为1，不设置反向减伤。普通攻击保持原有伤害。每只妖兽具有单一五行属性，战斗中显示属性；MVP默认同一秘境内妖兽使用同一属性。技能通过点击按钮释放，一次点击释放一次；法力不足或攻击冷却中不会扣法力。

## v0.8 三入口与品质（替代旧导航及直接付费学技能规则）

底部只保留外出、回家、人物。外出展示像素地图，点击地图商店、秘境石门和订单告示进入对应功能；回家展示家园，点击住宅、药田、炼丹洞进入功能。住宅内修炼、升级与家具经营。人物内管理装备、技能、背包和债务；原仓库更名背包。

生产品品质为粗制、初级、中级、高级、稀有、传说；仙草、妖兽内丹无粗制档，从初级到传说。种子、矿物、丹药、技能书、武器、装备按六档管理，丹炉已有六档。背包区分同类物品不同品质。商店可按品质筛选，初版高级物品筑基、稀有及传说物品金丹解锁。价格、属性和门槛为MVP默认数值。

技能通过购买技能书并研读学习，不再直接支付学习费；书籍消耗一份。相同或较低品质的已学技能书不能重复研读；较高品质升级技能，默认每级品质提升15%技能伤害。初始金锋剑气与已学旧技能保留，秘境仍最多携带四种。

播种优先使用对应作物最高品质种子，粗制或初级种子产出初级仙草，更高品质种子产出同阶仙草。高阶仙草、内丹在后续秘境与扫荡中获取：前两境初级，第三四境中级，第五六境高级，第七八境稀有，第九十境传说。炼丹可用同种较高品质材料替代，优先消耗低品质库存。材料不会因为带品质标签而成为可服用品。洗髓天灵丹保持传说、不可交易。


## v0.9 炼丹等级与成功率

用户确认：新增炼丹等级，成功率与修为及炼丹等级绑定。

MVP默认：炼丹等级初始1级，每100炼丹经验升一级，上限10级。成功获得10经验，失败不获得经验。失败同样消耗本次材料、精力，不产出丹药；成功产出一颗。旧存档每次成功炼丹记录换算10经验，已有资产保留。

修为强度 = 境界序号×10 + 境界内等级−1 + min(当前修为/80,1)，炼气、筑基、金丹序号为0、1、2。成功率 = clamp(round(70 + 修为强度×2 + (炼丹等级−1)×5 − 丹药品质序号×12),10,100)%。粗制至传说的品质序号为0至5。初始炼气五级、炼丹1级炼粗制丹药成功率78%。突破后的境界成长延续修为强度，消耗突破进度不会降低已达到的修为强度。

炼丹洞显示等级、经验进度与每个丹方当前成功率，炼制后提示成功或失败。丹炉及境界门槛继续生效。数值为初版默认、待平衡设定，替代旧版必定成丹规则。


### v0.9.1 炼丹结算修订

炼丹成功后增加10经验，经验条增长，满100经验升一级。失败材料作废，不产丹、不增加经验；本次精力消耗保留。


### v0.9.2 住宅室内

点击家园住宅后切换为独立像素室内背景，可点击蒲团修炼、门口出门；购置竹榻后可在室内点击休养，购置储物柜后可点击打开背包。房屋升级、家具购买和修炼面板保留。


### v0.9.3 炼丹费用

炼制丹药不消耗灵石，只消耗丹方材料和精力。零灵石也能炼制；成功增长炼丹经验，失败材料作废且不增加经验。丹炉升级和购买材料仍按原规则花费灵石。


### v0.9.4 丹炉升级材料

商店不出售丹炉，保留各品质赤铜矿出售。丹炉只能在炼丹洞升级，同时消耗灵石与矿石。五次升级分别需要180/600/1200/3000/8000灵石及2/4/8/12/20份赤铜矿，数量为MVP默认值；任意品质可用，优先消耗低品质库存。任一资源或境界不足不能升级，已有资产不扣除。炼丹本身仍不消耗灵石。


### v0.9.5 丹方材料修订

所有品质丹方移除矿石需求，炼丹不消耗矿石或灵石，只消耗丹方中的灵药仙草、妖兽内丹及精力。矿石用于丹炉升级，升级仍需矿石与灵石。以本条为最新规则。


## v0.10 商店与集市

商店不出售任何传说级物品，展示五行、品质、效果、使用或解锁要求、材料用途等详细信息。外出地图新增可点击的山间集市，使用已有透明摊位美术。

集市按游戏日每七日刷新六个摊位，仅展示名称和价格，每摊限购一件；购入后在背包或人物中查看详细属性。MVP默认价格为商店标价80%，每批5%概率有一件传说级货物，其余为粗制至稀有。洗髓天灵丹与丹炉不进入集市交易。
