# H5 包

当前上传快照为 v0.16.13，已成功运行 npm ci 与 npm run build。

由于上传通道无法接受整份约36MB的 ZIP 文件，包以2MB分片保存在 h5-v0.16.13 目录。下载完整仓库后，在项目根目录运行：

```sh
node scripts/restore-h5-package.mjs
```

脚本按顺序合并分片并检查 SHA-256，生成 release/yilu-chenmeng-h5-v0.16.13.zip。解压后即为可部署的完整 H5 静态文件。

也可运行 npm ci 和 npm run build，从源码重新生成 dist。
