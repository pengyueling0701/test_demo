# 古风修仙种田游戏设定

> 文档版本：基础设定 v0.8  
> 更新日期：2026年10月6日  
> 状态：基础策划方案，已有像素风 H5 MVP；完整游戏与平台发布尚未完成。

## 1. 游戏定位

一款面向 TapTap 创意工坊手机端的像素风 H5 修仙种田经营与动作探索游戏。玩家扮演负债累累、资质低劣的底层散修，在乡下经营药田、炼制丹药、偿还债务，并寻找改变资质的机会。筑基后解锁御剑飞行，前往秘境，以类银河恶魔城的横版动作探索方式战斗并获取资源。

以手机竖屏为唯一游玩布局，人物、药田、住宅、道具和战斗采用像素风。场景切换置于屏幕底部，手机端用固定底部菜单进入药田、丹房、商店、订单、修炼装备、住宅、债务与秘境。背景、角色、丹药与道具使用生图模型制作并作为本地素材接入。

点击场景内药田打开操作弹窗：空地展示种子库存与播种按钮，生长期展示剩余游戏日与预计产量，成熟后展示收获按钮。关闭弹窗不执行操作，成功播种或收获后返回场景。

体验重点是从破旧老屋起步的生活经营、周期性催债带来的取舍，以及逐步改善住宅和修炼条件的成长感。游戏名称暂未确定。

### 设定来源说明

本次新增的**用户确认规则**：开局为炼气五级；筑基后解锁御剑飞行并可前往秘境；秘境存在危险妖兽；战斗采用类银河恶魔城模式；可服丹回血且受丹毒限制；加入武器与装备系统。文中统一使用“炼气”作为“练气”的术语写法。战斗操作、装备槽位与具体丹毒限制方式为下文标注的初版建议。

- **用户确认规则**：主角身世与奇遇、灵石货币、初始贷款与资金、30日催债、每期1%利息、有现金仅收现金、零现金才扣灵药仙草、无可抵债资产时失败、境界关联贷款余额上限、住宅升级与家具的轻度经营增益；商店购买种子、炼丹材料、丹炉与丹药，高级丹药随境界解锁，提升资质的极品丹药不可在商店买卖；仙草可出售或炼丹，丹药可自用或出售，道友订单每7个游戏日刷新。
- **初版默认设定**：炼气起步、境界额度表、住宅阶段、功能家具示例、游戏时间推进方式、库存扣取顺序与超额找零、同类家具增益规则，以及主线完成后的继续经营。这些补充已纳入确认的文档方案，具体平衡数值仍可在后续开发中调整。

## 2. 世界观与故事背景

修仙世界中，灵石既是交易货币，也是底层修士获取修炼资源的重要手段。主角是一名缺乏宗门支持、修炼资质低劣的底层散修，为提升实力借下大量灵石，却未能获得足以偿债的收入。

债主上门，威胁若不还债，就将主角拆解并出售器官抵债。主角无奈躲到乡下的破旧老屋，试图暂避追债。在清理老屋时，他意外翻出一本失传已久的丹方和一座破败丹炉。

丹方其中一页记载了一种能够改变修炼资质的极品丹药。虽然主角暂时无法炼制，但这让他看见了改变命运的可能。他开始开垦药田、种植灵药仙草，通过炼丹与交易维持生计，逐步升级丹炉并收集极品丹药所需材料。这种丹药无法在商店购买，也不能出售给商店，主角需要自行炼制并服用。

债主的威胁仅作为文字剧情背景，以含蓄方式表现，不设计器官交易玩法或血腥展示。

## 3. 主角与初始状态

主角开局依靠有限资金、基础生产条件与丹方知识谋生。资质较差意味着修炼效率较低，并不意味着无法种田、炼丹或突破境界。

| 项目 | 初始状态 |
|---|---|
| 身份 | 无宗门支持的底层散修 |
| 修炼资质 | 低劣 |
| 修仙境界 | 炼气五级 |
| 未偿贷款 | 1,000,000 灵石 |
| 现有资金 | 500 灵石 |
| 当前贷款额度 | 1,000,000 灵石 |
| 可借金额 | 0 灵石 |
| 住宅 | 破旧老屋 |
| 生产条件 | 四块普通土地药田、少量免费入门种子 |
| 炼丹条件 | 无需修复、可炼粗制丹药的破败丹炉、失传丹方 |
| 长期线索 | 丹方中改变资质的极品丹药 |

入门作物必须能够在首次催债前完成收获。免费种子支持首次种植；具体种子数量、作物周期和丹炉升级成本暂不制定完整数值表。

## 4. 种田与炼丹循环

**购买种子与材料 → 种植灵药与仙草 → 收获 → 卖给商店、炼丹或交付道友订单 → 获得灵石 → 还款、改善住宅、投入生产与修炼。**

炼出的丹药可以自行服用，也可以出售给商店获取收入；提升资质的极品丹药不进入商店买卖循环。

筑基后的资源循环扩展为：**种田炼丹准备补给 → 装备武器与防具 → 御剑前往秘境 → 战斗探索获取资源 → 返回住宅整理库存 → 炼丹、修炼、交付订单与还款。**

### 4.1 种田

玩家可以在商店购买仙草种子，在农田中种植灵药与仙草，随游戏内时间推进完成生长和收获。收获物进入库存，可卖给商店换取灵石，也可保留作为炼丹材料或用于符合要求的道友订单。保留材料会减少当下收入，但为更高价值的丹药生产和主线目标提供条件。

### 4.2 炼丹

玩家根据丹方准备材料，逐步升级丹炉并建立炼丹能力，也可以花费灵石在商店购买炼丹材料与炼丹炉。丹药可自行服用，获得对应的修炼或其他丹药效果，也可卖给商店。低级丹药在前期即可购买，高级丹药在主角达到对应修仙等级后解锁。

改变资质的丹药属于极品丹药，是独立于普通高级丹药的主线目标，需要积攒材料并改善炼丹条件。无论境界多高，商店都不出售这种丹药，也不收购玩家炼出的该丹药。基础文档不制定完整配方、成功率、售价、服用效果或消耗表。

### 4.3 经营取舍

玩家需要在偿还贷款、购买生产资源、修炼成长与住宅投入之间分配资金。可交易的炼丹成品可以出售获得现金，也可以留作自用或交付订单；提升资质的极品丹药不能卖给商店。在本版规则中，成品丹药不属于债主可直接扣取的灵药、仙草库存。

### 4.4 商店交易与解锁

| 物品 | 玩家从商店购买 | 玩家卖给商店 | 主要用途 |
|---|---|---|---|
| 仙草种子 | 可以 | 本版不定义 | 播种与持续生产 |
| 炼丹材料 | 可以 | 收获的灵药、仙草可以；其他材料回收规则待定 | 炼制丹药 |
| 炼丹炉 | 可以 | 本版不定义 | 建立或改善炼丹条件 |
| 低级丹药 | 前期即可购买 | 可以 | 自行服用或获取收入 |
| 普通高级丹药 | 达到对应修仙等级后解锁购买 | 可以 | 自行服用或获取收入 |
| 提升资质的极品丹药 | 永不出售 | 不收购 | 自行炼制并服用，完成主线目标 |

购买扣除现有资金并获得对应物品，资金不足不能购买；出售扣除库存物品并增加现有资金。普通高级丹药的具体境界门槛留待后续数值策划，商店购买解锁不自动授予对应丹方或炼制能力。

### 4.5 道友订单任务

玩家可以完成其他道友提出的订单，提交指定种类与数量的物品，获得灵石奖励。订单展示需求物品、需求数量与灵石报酬，玩家可结合种植和炼丹计划选择完成。

订单每隔7个游戏日刷新一次，与30日催债周期分别计时；退出游戏不累计刷新时间。交付时检查库存是否满足全部需求，满足后扣除需求物品并发放奖励，每份订单只能领取一次报酬。库存不足时不能完成交付，不扣取部分物品。

初版默认开局提供第一批订单，此后每经过7个游戏日替换未完成的订单；不设置额外失败罚金。提升资质的极品丹药不作为普通订单需求，避免消耗主线目标物品。这些属于新增的初版默认设定。每批订单数量、报酬、难度与境界关联留待后续策划。

### 4.6 药田扩建与特殊土地

用户确认：初始药田为普通土地；后期随房屋升级可花费灵石扩充药田；部分特殊草药需要特殊土地。房屋升级提高可容纳药田数量，不自动新增药田；扩建和土地改造分别付费。

MVP采用以下初版数值，后续可调整：

| 住宅阶段 | 药田数量上限 | 新增一块普通药田的费用 |
|---|---:|---:|
| 破旧老屋 | 4块 | 初始容量已满，需先升级 |
| 整修木屋 | 6块 | 400灵石 |
| 乡间小院 | 8块 | 800灵石 |
| 修仙宅院 | 12块 | 1,200灵石 |

| 土地类型 | 改造解锁住宅 | 改造费用 | 对应特殊草药 | 成熟周期 | 基础产量 |
|---|---|---:|---|---:|---:|
| 普通土地 | 破旧老屋 | 0 | 青灵草 | 2日 | 3株 |
| 灵土 | 整修木屋 | 800灵石 | 月华仙草 | 3日 | 2株 |
| 赤炎土 | 乡间小院 | 1,400灵石 | 焰心草 | 4日 | 2株 |
| 寒霜土 | 乡间小院 | 1,800灵石 | 霜露仙草 | 4日 | 2株 |

- 新扩建的药田均为普通土地。只能改造空田，有作物时需先完成收获。
- 青灵草可在全部土地上种植；月华仙草、焰心草、霜露仙草分别严格要求灵土、赤炎土、寒霜土。土地不匹配不能播种，不扣种子或精力。
- 三种特殊作物在筑基后解锁种子购买。种子、境界、土地和精力条件全部满足后方可播种。
- 收获后土地类型保留。切换土地支付目标类型的改造费用；恢复普通地免费，不返还原改造费用，同类型不重复改造。
- 产量受种植熟练度影响；特殊土地本版用于种植条件，不直接叠加产量增益。
- 手机竖屏每片展示四块药田，可翻页管理。药田弹窗展示土地类型、种子选择、生长状态与改造选项。
- 所有收获的草药均可按既有规则出售或抵债；土地和未收获作物不参与抵债。土地条件仅限制种植，不改变既有商店购买与秘境获取规则。
- 月华仙草继续用于既有高级与极品丹药配方；焰心草和霜露仙草在MVP中可交易、抵债，专属丹方留待后续设计。

药田扩建、改土不会自动减少贷款，不直接提高贷款额度，也不在本版消耗游戏日。

## 5. 修仙成长与贷款额度

资质影响修炼效率。玩家在住宅内的蒲团上修炼，积累修为经验；每80点修为可手动突破一个境界内等级，突破时消耗80修为。炼气十级升筑基属于大境界突破，必须额外消耗1颗筑基丹；丹药不足时不会扣除修为。筑基丹可在商店丹药栏购买，原型暂定1,800灵石，不能直接服用或卖给商店。境界提升同时提高贷款额度，并按对应门槛解锁商店中的普通高级丹药，为经营与修炼提供更多选择；新增借款也增加未来偿债压力。提升资质的极品丹药不随境界提升进入商店。

贷款额度表示**当前允许持有的未偿贷款余额上限**，不是历史累计借款上限。还款恢复可借额度；当前额度由修仙境界和剩余寿元共同决定。用户已确认加入人物属性设计，并明确寿元也影响贷款额度。

### 5.1 人物属性

| 属性 | 作用与成长方式 |
|---|---|
| 境界 | 表示成长阶段，突破后提高贷款基础额度并解锁普通高级丹药 |
| 修为 | 当前境界的修炼进度，通过修炼和服用相应丹药积累，满足条件后突破 |
| 资质 | 决定修为获取效率，开局低劣，服用提升资质的极品丹药后永久提高 |
| 精力 | 种植、收获、炼丹等劳动消耗，休息恢复；住宅和床榻等家具可改善恢复效果 |
| 神识 | 影响炼丹控制能力与成功率，随修炼成长 |
| 丹毒 | 连续服用丹药积累，过高时降低丹药效果，休养逐渐消退 |
| 种植熟练度 | 通过种植成长，提高收获数量与仙草品质 |
| 炼丹熟练度 | 通过炼丹成长，降低材料损耗并提高成丹品质 |
| 道友信誉 | 完成订单提高，逐步解锁报酬更高、要求更难的订单；普通刷新或未完成订单不扣信誉 |
| 寿元 | 表示寿命上限与剩余可生存时间，境界突破增加寿命上限，剩余寿元参与贷款额度计算 |
| 气血 | 当前生命值与生命上限，受到妖兽或环境伤害时减少，恢复类丹药用于回血 |
| 灵力 | 当前灵力与灵力上限，初版建议用于战斗技能消耗，与劳动精力分开 |
| 攻击 | 影响武器攻击与战斗技能伤害，由人物成长及装备共同提供 |
| 防御 | 影响承受伤害，由人物成长及装备共同提供，具体减伤公式待定 |

资质以低劣、普通、良好、卓越、天灵等档位展示。资质影响效率，修为表示进度，境界表示阶段；种植与炼丹熟练度不替代境界。初版采用一套劳动精力，不为每种劳动分别设置体力条。

寿元界面分别展示年龄、寿命上限与剩余寿元，计算关系为 `剩余寿元 = max(0, 寿命上限 − 年龄)`。年龄随游戏内时间增长，离线不增长。具体日年换算、初始年龄、各境界寿命上限及寿元耗尽结局留待后续设计，不套用现实等待时间。

### 5.2 寿元与授信

初版采用以下计算结构，系数数值尚未确定：

```text
当前贷款额度 = floor(境界基础额度 × 寿元系数)
可借金额 = max(0, 当前贷款额度 − 未偿贷款)
```

在同一境界下，剩余寿元越少，寿元系数越低；增加剩余寿元可恢复或提高额度。系数以剩余寿元为依据，保持单调不减，具体阈值、上限和增幅待平衡。开局寿元对应系数1，保留初始100万灵石额度和额度占满的状态。

年龄增长、寿命上限增加或境界突破时重新计算额度。突破增加寿命上限，从而增加剩余寿元，不重置年龄。额度降低不会减免既有贷款，也不触发额外即时催收或失败；余额达到或超过新额度时暂停借款，仍按原30日催债规则处理。

贷款界面展示境界基础额度、剩余寿元、寿元系数和最终额度，帮助玩家理解额度变化原因。具体系数与寿元数值属于后续数值策划，不在本版编造固定值。

## 6. 资产、贷款与催债机制

### 6.1 资产展示

统一以整数灵石计价。资产界面分别显示现有资金、未偿贷款、当前贷款额度与可借金额；库存与住宅单独展示。

- **现有资金**：当前可用于交易、修炼、还款和住宅投入的灵石。
- **未偿贷款**：尚未偿还的本金与已经计入的利息。
- **当前贷款额度**：由当前境界基础额度与剩余寿元对应的系数共同决定的贷款余额上限。
- **可借金额**：`max(0, 当前贷款额度 − 未偿贷款)`。

贷款余额不计入可用资金。新借款到账后，才增加现有资金。

### 6.2 借款与主动还款

借入金额不得超过当前可借金额。借款成功后，现有资金与未偿贷款同时增加相同金额。

主动还款金额不得超过现有资金与未偿贷款中的较小值。还款后，二者同时减少相同金额，无手续费，并重新计算可借金额。

### 6.3 催债周期与利息

每30个游戏日催债一次。时间随游戏内行动推进，退出游戏不累计催债时间。每次催债先计息，再催收：

```text
新增利息 = ceil(催债前未偿贷款 × 1%)
计息后未偿贷款 = 催债前未偿贷款 + 新增利息
```

新增利息向上取整到整数灵石，按当时全部未偿贷款计算。利息可以使余额超过当前贷款额度；余额达到或超过额度时，可借金额为零，不能新增借款。

### 6.4 催收顺序

计息后，根据债主到访时的现金余额选择本次催收分支：

| 到访时状态 | 本次处理 |
|---|---|
| 现有资金大于零 | 收取现金，金额为现有资金与全部欠款中的较小值；同步减少贷款，同次不扣库存 |
| 现有资金为零 | 扣取灵药、仙草库存，按出售价值抵债 |

现金足够还清时，只收欠款金额，剩余现金保留。现金不足时，即使收取后变为零，也不会转入库存催收分支。

库存按单位售价从低到高逐件扣取，同价按固定物品顺序处理，直至贷款清零或可扣库存耗尽。最后一件物品的价值若超过剩余欠款，贷款归零，超出部分返还为现金。

仅灵药与仙草可直接用于库存抵债。住宅、家具、农田、丹炉、丹方、种子、成品丹药、武器、装备与非草药类秘境材料不在本版直接抵债范围内。秘境获得的灵药、仙草仍按同类库存参与抵债，来源不改变催收规则。

### 6.5 催收结束与失败判断

催收结束后，若仍有欠款，且现有资金与可抵债的灵药、仙草库存均为零，触发失败结局。住宅和生产设施仍在、持有种子或成品丹药，均不豁免这一失败条件。

贷款清零后停止计息与催债；若玩家后续重新借款，则恢复债务规则。重新借款后的首次催债以该次借款起算30个游戏日，作为初版时间规则补充。

### 6.6 计算示例

以下催收示例均先计息，再扣取资产。

| 情景 | 操作前状态 | 结果 |
|---|---|---|
| 初始额度占满 | 炼气，贷款1,000,000，资金500 | 可借金额为0 |
| 主动还款恢复额度 | 初始状态主动还款200 | 贷款999,800，资金300，可借200 |
| 新借款 | 贷款999,800，资金300，借入200 | 贷款1,000,000，资金500，可借0 |
| 突破提高额度 | 贷款1,000,000，突破筑基，重新计算后的寿元系数为1 | 额度2,000,000，可借1,000,000 |
| 寿元下降导致超额 | 假设重新计算后额度800,000，贷款900,000 | 可借0，贷款仍为900,000；不立即催收，沿用原周期 |
| 有现金，不扣库存 | 贷款1,000,000，资金500，持有灵药 | 加息10,000，收现金500；贷款1,009,500，资金0，灵药保留，未失败 |
| 零现金，以库存抵债 | 贷款1,000，资金0；两件灵药分别价值100、200 | 加息10，扣两件共抵300；贷款710，现金及可抵债库存均为0，失败 |
| 库存超额抵债 | 贷款100，资金0；一件仙草价值150 | 加息1，扣仙草后贷款0，返还49灵石，不失败 |
| 现金足够还清 | 贷款100，资金200 | 加息1，收101；贷款0，资金99，停止催债 |
| 收现金后资产耗尽 | 贷款1,000，资金100，无灵药仙草 | 加息10，收100；贷款910，资金与可抵债库存均为0，失败 |
| 利息向上取整 | 贷款101 | 新增利息2，计息后贷款103 |

## 7. 住宅升级与家具

### 7.1 住宅阶段

| 阶段 | 住宅 | 主要用途 |
|---|---|---|
| 初始 | 破旧老屋 | 提供基础居所与有限储物、家具摆放条件 |
| 第一次升级 | 整修木屋 | 改善外观，扩大储物能力，增加家具位置 |
| 第二次升级 | 乡间小院 | 扩展生活与经营空间，解锁更多家具种类 |
| 第三次升级 | 修仙宅院 | 提供更完善的居住与经营辅助条件 |

玩家依次花费灵石升级住宅。升级改善外观、扩大储物能力，并解锁更多家具摆放位置与种类。具体升级价格、容量和位置数量不在本版制定。

### 7.2 家具类型

| 家具类型 | 示例 | 作用 |
|---|---|---|
| 装饰家具 | 屏风、灯具、桌椅 | 用于古风住宅布置与外观变化 |
| 功能家具 | 储物柜 | 增加储物容量 |
| 功能家具 | 晾药架 | 辅助灵药处理 |
| 功能家具 | 炼丹工作台 | 提供轻度炼丹效率增益 |

功能增益按家具种类生效，同类取最高等级，不通过重复摆放叠加。例如，同时摆放两个储物柜，只采用其中最高等级的容量增益；不同种类家具可分别提供自身作用。

### 7.3 住宅与经济的关系

购买家具和升级住宅都扣除现有资金，资金不足时不能操作。住宅投入不会自动减少贷款，也不会直接提高贷款额度；额度由修仙境界和剩余寿元共同决定。

住宅和家具不参与债主催收，但投入过多可能造成现金紧张。它们提供外观与轻度经营改善，不能替代还款或规避资产耗尽的失败条件。

## 8. 御剑、秘境战斗与装备

### 8.1 筑基与御剑飞行

主角从炼气五级起步，前期以种田、炼丹、修炼和订单经营为主。突破筑基后解锁御剑飞行，获得前往秘境的能力。御剑作为住宅与秘境之间的出行方式；是否允许在秘境内部自由飞行留待后续设计，不能默认获得飞行后绕过所有地形与探索关卡。

### 8.2 类银河恶魔城探索

秘境采用手机竖屏呈现的侧视实时动作与相互连通的区域地图，包含危险妖兽、地形障碍、隐藏路径、资源点与强敌。角色沿关卡横向移动，竖屏镜头跟随主角，而非缩小整张横屏地图。玩法包括战斗、跳跃移动、路线探索，以及获得新能力后返回旧区域开启此前无法通过的路径。

初版基础操作包括移动、跳跃、武器攻击、闪避、技能和快捷服丹。手机左侧提供移动按钮，右侧提供拇指操作的跳跃、攻击、闪避、技能与服丹按钮。横转手机时提示切回竖屏并暂停战斗，转回继续；关键攻击有可辨识的前摇与躲避机会，难度同时取决于操作、境界、装备和补给。不能仅以侧视战斗或线性闯关替代能力解锁与回访探索。

秘境资源可包含灵药仙草、炼丹材料、装备材料、武器与装备。具体掉落表、材料商店回收范围和强敌奖励待定；特殊材料可用于后续高级炼丹与装备成长，但本版不强制规定极品丹药必须依赖某一秘境掉落。

### 8.3 战斗服丹与丹毒

战斗中可以消耗库存中的恢复类丹药回复气血，不超过气血上限。战斗服丹与修炼服丹共用同一个丹毒属性，进入或离开秘境不重置丹毒。

初版建议：丹毒升高逐步降低丹药恢复效果；达到丹毒上限时，禁止继续服用产生丹毒的丹药。成功服丹同时消耗一颗丹药、结算回血并增加对应丹毒；被限制时不消耗丹药。具体丹毒上限、每种丹药毒性与衰减幅度待平衡。

丹毒通过休养逐渐消退；战斗中不提供足以支持连续无限服丹的自动消退。服丹动作耗时、冷却与是否可被打断留待动作设计。界面显示气血、丹毒和快捷丹药数量，并提示无法服丹的原因。

### 8.4 武器与装备

引入独立的武器与装备系统，槽位为独立武器及头部、上衣、裤子、鞋子、背饰、挂饰、项链、戒指。主武器影响攻击范围、攻击动作与伤害；衣袍主要提供防御与气血增益；饰品提供灵力或其他辅助属性。具体武器种类、词条与品质阶梯后续设计。

装备可以存在境界要求，未满足要求不能穿戴。装备获得不自动替换当前装备，玩家在装备界面比较属性后选择穿戴。初版不设置耐久损耗；商店可购买已解锁武器与装备，强化、锻造和装备回收暂未实现。

武器和装备作为非草药资产，不由债主直接扣取；持有它们不豁免既有的现金与灵药仙草耗尽失败条件。装备提升战斗能力，不直接改变贷款额度或资质。

### 8.5 待定的探索结算规则

秘境出行与探索需要接入统一游戏日历，使种植、7日订单刷新、30日催债和寿元继续遵循同一时间来源。出行消耗、秘境内时间速度、催债日跨越处理与暂停规则后续确定，不能默认秘境内永久冻结经营时间。

气血归零后的处理、撤离方式、检查点、资源保留或损失，以及秘境区域与妖兽刷新规则尚未确定。战斗失败与债务失败分别定义，不将气血归零直接等同于既有债务失败结局。

### 8.7 通关后一键扫荡

用户确认：通关一个秘境后解锁该秘境的一键扫荡，次数为1次，经过七个游戏日恢复。

- 各秘境独立记录。首次成功通关后可立即扫荡一次，使用后从使用当天起等待完整7个游戏日，再恢复为1次，未使用的次数不累积。
- 扫荡直接获得该秘境的基础资源奖励，不再进入动作战斗。MVP不额外消耗灵石、丹药、精力或游戏日，不改变当前气血与丹毒；奖励数量为可调整的初版数值。
- 再次手动通关不重置已有冷却。退出游戏不推进恢复时间，原有恢复日期随存档保存。
- 背包不足时不领取、不扣扫荡次数；未通关或冷却未结束不能领取，避免重复领奖。
- 界面显示可用次数或剩余恢复天数，点击即可领取，不增加二次确认弹窗。

验证仅保留资源、等级门槛、土地条件、冷却和重复领奖等关键规则，不进行重复的素材格式或地图配置检查。

## 9. 阶段目标与结局

| 阶段 | 玩家目标 |
|---|---|
| 起步 | 完成首次播种与收获，建立初步收入 |
| 稳定经营 | 升级或购买丹炉、开始炼丹与完成道友订单，准备应对周期性催债 |
| 成长 | 从炼气五级修炼至筑基，解锁御剑与秘境；扩大生产，改善住宅并提升装备 |
| 秘境探索 | 准备丹药，战斗获取资源，解锁能力并回访探索区域 |
| 长期追求 | 收集改变资质的极品丹药材料，减少债务 |
| 主线完成 | 清偿全部债务，并炼成、服用改变资质的丹药 |

**成功条件**：清偿全部债务与服用改变资质的丹药两项都已完成，顺序不限。主线完成后可继续种田、炼丹、修炼、秘境探索与布置住宅。

**失败条件**：一次催收结束后，未偿贷款仍大于零，且现有资金和可抵债库存均为零。触发失败结局后，本局结束，可重新开始。

## 10. 规则验收清单

- [ ] 初始境界为炼气五级，资金为500灵石，贷款为1,000,000灵石，炼气额度占满，可借金额为零。
- [ ] 借款同时增加资金与贷款；主动还款同时减少二者，还款无手续费。
- [ ] 境界提升提高额度，历史累计借款不占用已偿还的额度。
- [ ] 开局寿元系数为1，基础额度表与初始100万灵石额度一致；其他寿元状态按系数重算。
- [ ] 同境界下剩余寿元下降不增加额度，剩余寿元增加不降低额度；突破增加寿命上限但不重置年龄。
- [ ] 寿元导致额度低于贷款时，可借金额为零，既有债务不变，不额外触发即时催收或失败。
- [ ] 人物属性、资产和设施信息分别展示；丹毒影响服丹效果，熟练度影响经营，道友信誉通过订单成长。
- [ ] 每30个游戏日先计1%利息，新增利息向上取整，再催收；离线不推进周期。
- [ ] 利息超过额度时可借金额为零，不将利息截断到额度上限。
- [ ] 到访时有现金仅扣现金，同次不因现金扣完而继续扣库存。
- [ ] 到访时零现金才扣灵药仙草，顺序稳定，超额抵债返还差额。
- [ ] 现金不足但仍有灵药仙草库存时不失败；催收后欠款未清且二者均为零时失败。
- [ ] 住宅、家具和其他非抵债物品不参与直接催收，也不豁免失败条件。
- [ ] 房屋与家具操作资金不足时不能执行；同类功能家具仅最高等级生效。
- [ ] 贷款清零后停止计息催债，重新借款后恢复；主线完成后支持继续经营。
- [ ] 入门作物在首次催债前可以收获，种田炼丹循环能够从初始资源启动。
- [ ] 商店可购买仙草种子、炼丹材料、炼丹炉和低级丹药；购买扣款、出售扣库存并获得灵石，资金不足不能购买。
- [ ] 普通高级丹药达到对应境界后解锁购买，未达到境界不能购买；购买解锁不自动解锁炼制能力。
- [ ] 任意境界下，商店均不出售、不收购提升资质的极品丹药，该丹药也不进入普通订单需求。
- [ ] 收获的仙草可卖给商店或用于炼丹，丹药可自行服用或出售，极品丹药遵守交易例外。
- [ ] 道友订单开局提供首批，此后每7个游戏日刷新；离线不推进刷新，未完成订单刷新替换且无罚金。
- [ ] 订单交付一次性扣取全部所需物品并发放一次灵石奖励；材料不足不扣物品、不发奖励，已完成订单不能重复领取。
- [ ] 炼气阶段未解锁御剑秘境出行；突破筑基后解锁，境界内等级不额外改变基础贷款额度。
- [ ] 秘境包含互通区域、能力门槛与回访路径，以及妖兽战斗和资源获取。

秘境地图、能力解锁顺序、动作参数、妖兽数值、装备词条与成长、战斗丹毒数值、失败惩罚及探索时间结算属于后续详细设计。第8节标注的初版建议用于明确方向，不视为用户已逐项确认的最终规则。

TapTap 创意工坊手机端 H5 为当前目标发布形态。已将官方发布流程与待确认事项整理为 MVP 目录中的《TapTap创意工坊手机端发布调研.md》；尚未上传包体、自测或提审，本版不对可直接上线作出承诺。

人物属性具体数值、寿元日年换算、初始年龄、各境界寿命上限、寿元系数及寿元耗尽结局留待后续设计。寿元与境界共同影响额度为用户确认规则；本版公式、开局系数1以及额度降低不额外催收为保持既有机制一致而补充的初版默认设定。


## 丹炉品质、人物与仓库（最新规则）

破败丹炉无需修复，开局可直接炼制粗制丹药。品质依次为粗制、初级、中级、高级、稀有、传说。花灵石逐级升级丹炉，升级后能炼对应及更低品质。洗髓天灵丹属于传说级，不能在商店买卖。

商店新增武器与装备。装备分为头部、上衣、裤子、鞋子、背饰、挂饰、项链、戒指；购买后主动穿戴，同部位替换生效，不叠加。增加气血上限不会免费回血。

底部秘境之后新增人物、仓库入口。人物展示八个部位、武器及实际属性。仓库分类为种子、灵药仙草、矿物、妖兽材料、丹药、武器装备，可出售可交易物品、服丹和穿戴。装备收藏独立于材料仓储容量。

MVP默认数值：丹炉依次为破败、青铜、精铁、灵纹、紫霄、太虚；逐级费用180、600、1200、3000、8000灵石。灵纹需筑基，紫霄与太虚需金丹。战斗优先使用现有最高品质回血丹，用尽后切换较低品质，共用丹毒限制。旧存档保留库存、武器、衣袍；旧最高丹炉迁移为灵纹丹炉。


## 五灵根与技能（最新确认）

主角为金木水火土五灵根，可学习全部属性技能。所有现有物品均归属单一五行，包括种子、草药、丹药、矿物、妖兽材料、武器装备、丹炉、土地、住宅家具、丹方和灵石。五灵根与低劣资质并存，洗髓提高资质，不改变灵根。五行克制按下文最新规则生效。

秘境最多携带四种已学技能，人物面板学习、携带和卸下。初版开局自带金锋剑气；青藤破阵、寒潮灵波、赤焰焚击、厚土震岳分别花250、300、400、350灵石学习。五技能消耗法力分别12、14、16、20、18，攻击范围及倍率不同。上述费用、技能名和数值为MVP默认设定。

粗制回灵丹与初级回灵丹可购买、炼制、自用及出售，回复40、65法力并产生18、16丹毒。满法力或满丹毒不能服用，丹毒降低回复效果；秘境回灵丹按钮优先使用高品质库存。所有丹药共用丹毒。旧存档补齐五灵根和初始技能，保留原有资产。


### 五行克制与技能点击

土克水、水克火、火克金、金克木、木克土。技能命中被克制属性妖兽时，伤害 = 人物攻击 × 技能倍率 × 2；其余属性关系倍率为1，不设置反向减伤。普通攻击保持原有伤害。每只妖兽具有单一五行属性，战斗中显示属性；MVP默认同一秘境内妖兽使用同一属性。技能通过点击按钮释放，一次点击释放一次；法力不足或攻击冷却中不会扣法力。


## v0.8 三入口与品质（替代旧导航及直接付费学技能规则）

底部只保留外出、回家、人物。外出展示像素地图，点击地图商店、秘境石门和订单告示进入对应功能；回家展示家园，点击住宅、药田、炼丹洞进入功能。住宅内修炼、升级与家具经营。人物内管理装备、技能、背包和债务；原仓库更名背包。

生产品品质为粗制、初级、中级、高级、稀有、传说；仙草、妖兽内丹无粗制档，从初级到传说。种子、矿物、丹药、技能书、武器、装备按六档管理，丹炉已有六档。背包区分同类物品不同品质。商店可按品质筛选，初版高级物品筑基、稀有及传说物品金丹解锁。价格、属性和门槛为MVP默认数值。

技能通过购买技能书并研读学习，不再直接支付学习费；书籍消耗一份。相同或较低品质的已学技能书不能重复研读；较高品质升级技能，默认每级品质提升15%技能伤害。初始金锋剑气与已学旧技能保留，秘境仍最多携带四种。

播种优先使用对应作物最高品质种子，粗制或初级种子产出初级仙草，更高品质种子产出同阶仙草。高阶仙草、内丹在后续秘境与扫荡中获取：前两境初级，第三四境中级，第五六境高级，第七八境稀有，第九十境传说。炼丹可用同种较高品质材料替代，优先消耗低品质库存。材料不会因为带品质标签而成为可服用品。洗髓天灵丹保持传说、不可交易。


## v0.9 炼丹等级与成功率

用户确认：新增炼丹等级，成功率与修为及炼丹等级绑定。

MVP默认：炼丹等级初始1级，每100炼丹经验升一级，上限10级。成功获得10经验，失败不获得经验。失败同样消耗本次材料、精力，不产出丹药；成功产出一颗。旧存档每次成功炼丹记录换算10经验，已有资产保留。

修为强度 = 境界序号×10 + 境界内等级−1 + min(当前修为/80,1)，炼气、筑基、金丹序号为0、1、2。成功率 = clamp(round(70 + 修为强度×2 + (炼丹等级−1)×5 − 丹药品质序号×12),10,100)%。粗制至传说的品质序号为0至5。初始炼气五级、炼丹1级炼粗制丹药成功率78%。突破后的境界成长延续修为强度，消耗突破进度不会降低已达到的修为强度。

炼丹洞显示等级、经验进度与每个丹方当前成功率，炼制后提示成功或失败。丹炉及境界门槛继续生效。数值为初版默认、待平衡设定，替代旧版必定成丹规则。


### v0.9.1 炼丹结算修订

炼丹成功后增加10经验，经验条增长，满100经验升一级。失败材料作废，不产丹、不增加经验；本次精力消耗保留。


### v0.9.2 住宅室内

点击家园住宅后切换为独立像素室内背景，可点击蒲团修炼、门口出门；购置竹榻后可在室内点击休养，购置储物柜后可点击打开背包。房屋升级、家具购买和修炼面板保留。


### v0.9.3 炼丹费用

炼制丹药不消耗灵石，只消耗丹方材料和精力。零灵石也能炼制；成功增长炼丹经验，失败材料作废且不增加经验。丹炉升级和购买材料仍按原规则花费灵石。


### v0.9.4 丹炉升级材料

商店不出售丹炉，保留各品质赤铜矿出售。丹炉只能在炼丹洞升级，同时消耗灵石与矿石。五次升级分别需要180/600/1200/3000/8000灵石及2/4/8/12/20份赤铜矿，数量为MVP默认值；任意品质可用，优先消耗低品质库存。任一资源或境界不足不能升级，已有资产不扣除。炼丹本身仍不消耗灵石。


### v0.9.5 丹方材料修订

所有品质丹方移除矿石需求，炼丹不消耗矿石或灵石，只消耗丹方中的灵药仙草、妖兽内丹及精力。矿石用于丹炉升级，升级仍需矿石与灵石。以本条为最新规则。


## v0.10 商店与集市

集市货物不设购买境界限制，装备穿戴要求继续生效。购买、售罄记录与本批货物保存进存档，重载或离线不刷新；到下一批才换货。资金或容量不足时不扣款、不标记售罄。概率、数量和折扣为初版待平衡数值。
