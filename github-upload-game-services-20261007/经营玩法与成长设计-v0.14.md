# 种药炼丹经营：第一、二阶段实施稿

版本：v0.14.0；日期：2026-10-06。

## 游戏定位

主要玩法为种药炼丹经营，核心卖点为底层散修逆天改命。修仙提供经营能力与长期成长，交易形成产物去向的选择，债务提供阶段压力。当前先把现有生产闭环做实。

## 第一阶段：让一批仙草有不同去向

直接出售换稳定现金；炼丹以精力、材料和失败风险换加工回报与经验；服丹换修为或探索补给；交订单换限量的需求溢价。没有新增炼丹灵石费用，矿石仍只用于丹炉升级。

丹药回收价以丹方基础材料直售价值为基础，最低加工倍率为 `1.45 + 品级 × 0.12`，向上取整到十灵石，同时保留原有更高回收价。商店售价至少为回收价除以0.75，避免八折集市采购后立即卖出获利。高阶丹药实际是否划算仍受成功率、材料品质和精力影响，不承诺每炉赚钱。

开局炼气五级粗制回春丹：2株青灵草直售180灵石；成丹售价270，成功率78%，平均回款约211，平均加工差额约31。出售原料不承担失败且节省18精力；炼丹有长期经验回报；服丹则放弃现金，换成长或补给。

丹房显示材料直售价值、成功出售回款、概率加权平均回款、加工差额、当前匹配订单、消耗材料与精力。预览与实际炼制均使用低品质优先的材料顺序，不足部分按基础材料估值；珍贵仙草代替普通材料时，加工差额可能转为负数。尚未满足材料或精力条件时不能开炉。

订单仍七日刷新、三份：基础仙草订单保持现有奖励；剑修订单交替需求回春丹与回灵丹；修炼订单在筑基后的下一轮刷新改为高级凝元丹。丹药订单奖励按所需丹药直售价的约1.4倍计算，一轮仅能交付一次。当前未完成订单不随突破立即替换，避免损失准备成果。

药田管理加入经营盘算与背包、订单、丹房入口。种植可明确选择持有种子的品质，默认低品质优先，避免误耗高阶种子。

## 第二阶段：成长改变做法

- 炼丹等级：仅成功获得经验，提高成功率。失败材料作废、不增加经验。
- 丹炉：用矿石与灵石升级，打开更高品级炼制能力，不与炼丹经验重复设置硬门槛。
- 炼气七级：自动领悟引露术。消耗12法力、8精力，对所有未成熟且未照料的作物生效，本轮每块产量+1。
- 筑基：自动领悟催生术。消耗24法力、12精力，对所有未成熟且未催生的作物生效，本轮提前1日成熟。同步保留特殊种子、御剑与秘境解锁。
- 金丹：开放现有稀有材料与高阶丹炉，向改变资质的丹药迈进。
- 住宅：保留储物、家具与药田扩充能力；土地类型决定特殊灵植的生产路线。

两种仙术均不推进日期，每种对一轮作物只能施展一次；标记随作物保存，读档不能重复刷收益。收获后新一轮可以重新施术。法力与精力构成成本，回灵丹获得新的经营用途。种植熟练度提供的额外产量上限为3，避免旧有无限增长让普通草药长期压倒所有其他生产路线。

住宅修炼面板增加成长路线与当前解锁状态，突破时提示新能力。经营内容留在管理弹窗中，保留画面主体与外出／回家／人物三个底部入口。

旧版本自动生成了许多同品级近似丹药，新商店与丹房展示清晰的主线品类：回春、回灵以及逐级修炼丹。旧物品ID与库存继续保留并可服用、出售；不清空资产、技能、任务或秘境。旧集市保留货物和售罄记录，仅首次迁移按新目录同步八折价格，防止缓存旧价格造成套利。已有订单不追溯改价。

## 验证记录

63项规则测试通过，新增覆盖加工预览、回收套利边界、仙术门槛与单次限制、读档、种子品质选择、订单轮换。构建通过。

两组生产模拟使用相同经营策略、不同炼丹随机种子，无新增贷款、无任务奖励、无集市倒卖。种子42的流程：第3日升级青铜丹炉、第7日炼气七级、第16日筑基；17次炼丹，失败1次；15次引露、10次催生。至第31日：交易26,370、订单5,660、支出2,420、净经营收入29,610；首期利息10,000，催收还款30,110；剩余贷款979,890、现金0、仙草8株，存活。种子147的同流程净收入30,366，亦存活。

原第一章含真实战斗帧循环的回归模拟也通过，通关并在第31日存活。上述均为程序模拟，不是真机试玩，不代表所有策略或所有随机结果都能存活。

## 接下来观察什么

试玩重点：是否会主动在卖草、加工、自用、订单间切换；是否为了引露术与催生术主动修炼；是否能理解贵材料替代导致的利润下降；催债后能否自然开启下一轮生产。

本阶段没有改动债务催收规则，也没有引入动态物价、联网交易或新增秘境。若试玩仍只有一种最优生产路径，下一步优先调整需求与丹方，而不是继续增加物品数量。
